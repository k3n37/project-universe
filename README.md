# cosmos

Curated portfolio orchestration repository connecting projects into one coherent engineering narrative.

## Purpose

This repo exists to organize the broader set of engineering projects into a visible portfolio system rather than a loose collection of unrelated repos.

## Role in the ecosystem

- Presentation and curation companion to `canvas`
- Downstream storyteller for `orbit`
- Neighbor to `summit`

## Status

Starter content and data model repo with ecosystem metadata.

## Tech stack

- TypeScript
- Markdown
